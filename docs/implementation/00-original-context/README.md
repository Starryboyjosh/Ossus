# Historical design records

This directory preserves the two original Spanish documents exactly as they were approved and revised before implementation planning.

They are not the active implementation specification.

Use them when:

- reconsidering the product boundary;
- comparing a proposed restructuring with the original intent;
- understanding why the Resolver was moved before the Researcher;
- auditing decisions that were simplified in the implementation plan;
- recovering rejected alternatives such as a same-repository candidate branch, a custom sandbox, or fourteen initial resource types.

Active instructions are written in English elsewhere in this package.
