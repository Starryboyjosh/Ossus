# WAVE-011 Summary — Ossus V0 release candidate

## Status

Planned.

## Technical summary

Packages the resolver-first V0 candidate with versioning, changelog, target binaries, seed Registry snapshot, checksums, clean-environment installation coverage, upgrade/rollback notes, and stated limitations.

## Practical plain-language summary

This prepares a testable first release that users can install and verify, while being clear about what Ossus does not yet provide.

## Expected evidence/deliverables

- V0 release candidate, checksums, seed snapshot, and release report.
- Artifact-install, CLI-smoke, golden-suite, activation-fixture, and checksum-verification evidence.
- Completed release checklist and explicit disclosure that Ossus provides neither a sandbox nor Researcher functionality.

## Dependencies/gates

Depends on WAVE-010 and requires Phase 3 gates to pass. Any release authorization is governed by Agent Review Authority.

## Remaining work

Produce and test the candidate artifacts, complete release documentation and rollback guidance, verify checksums, and record release authorization.
