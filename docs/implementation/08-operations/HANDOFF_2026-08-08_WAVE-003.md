## Technical summary

The Registry implementation is locally functional and tested. Release FTS5 is
now exercised by `crates/ossus-registry/tests/release_fts5.rs` on the existing
Linux/macOS/Windows CI matrix. ADR-021 proposes deterministic hashing of an
immutable Git tree/subpath with explicit framing, bounds, a global deadline,
Git environment isolation, literal pathspecs, full object-ID equality and
  submodule rejection. Independent review passed the hash controls; Closure found
  and the implementer corrected an embedded-NUL subpath gap. Independent
  re-review passed and the distinct Closure Agent accepted ADR-021 and the CI
  implementation on 2026-08-08.
